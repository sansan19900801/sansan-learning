# 交互式学习 Skill

> 把任意课题拆成连续的学习文章，像私教一样根据你的反馈和自测结果，动态调整下一篇的深度、角度和节奏，还会带你定期复习、结业验收。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

让 AI 教你学东西，常见两个毛病：一次倒给你一大堆、不管你懂没懂就往下讲；或者你说"懂了"它就信了，其实只是眼熟。这个 Skill 用「连续短文 + 主动回忆自测 + 反馈自适应 + 间隔复习」解决。

## 核心机制

1. **一篇一个能力点**：每篇开头写明"学完你应该能做到 X"，不贪多
2. **主动回忆自测**：篇末 2-3 道合上书才能答的题，答案放下一篇开头，分辨真懂还是假懂
3. **三路反馈自适应**：快速自评（懂了/半懂/没懂）+ 想要的讲法（类比/例子/动手/图解）+ 自测对错，共同决定下一篇怎么讲
4. **间隔复习**：每 3-4 篇自动插一篇复习，串联前面、重测易错点（不搞复杂算法）
5. **结业闭环**：学完出总复习地图 + 一个结合你真实场景的综合应用任务，过关才算学会
6. **因材施教的起点**：能轻量扫描当前项目，区分"你亲自写的（强证据）/AI 草稿（弱证据）/第三方材料（不算）"，不把"出现过"当成"你会了"
7. **时间预算**：按你每次能学多久控制单篇篇幅

## 明确不做

- 不做题库系统、闪卡引擎、SM-2 间隔重复算法
- 不做 K12 应试辅导、不代写营销内容
- 不遍历你的项目、不读密钥等敏感文件

## 你需要提供什么

- 想学的课题（或一段材料）、每次能学多久；之后每篇读完做下自测、写句反馈即可

## 产出结构

```text
学习课题/{课题名}/
├── 00-学习计划.md   # 目标、时间预算、知识基础、能力掌握追踪表
├── 01.md、02.md …   # 连续正课，每篇含能力点/正文/自测/反馈区
├── R1.md …          # 间隔复习篇
├── 99-结业验收.md   # 总复习 + 综合应用
└── assets/
```
